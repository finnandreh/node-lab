What is real

Runtime evidence

  • Node-RED runs in a pinned Docker image.
  • Buttons call the deployed flow over HTTPS.
  • The server validates input and applies the 30 °C rule.
  • Invalid input returns HTTP 400.

What is deliberately absent

Honest limits

  • No physical sensor, actuator, MQTT broker, or customer data.
  • No public editor or arbitrary flow deployment.
  • No live AI inference endpoint.
  • No shared visitor history, account, cookie, or analytics.
