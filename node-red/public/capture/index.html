Released functional rule

Limit minus validated temperature.

comfort_margin_c = configured_demo_temperature_limit_c - validated_temperature_c

Positive means below the chosen teaching limit, zero means exactly at the limit, negative means above it, and a missing observation returns null and displays Unavailable.

Workshop values remain live-generated emulation. This change does not connect hardware, customer data or live AI inference.
