# Node Lab authoring prompt

The complete, human-reviewed authoring prompt is published in the source
repository at `docs/AI-PROMPT.md`.

Build a transparent Node-RED lesson with fixed synthetic 22 C and 34 C input,
strict rejection of every other public value, one visible 30 C threshold, and
explicit JSON output. Keep browser history per visitor. State that no physical
device or live AI inference exists. Disable the production editor and expose no
arbitrary command, code or external action.

Source: https://github.com/finnandreh/node-lab/blob/main/docs/AI-PROMPT.md
