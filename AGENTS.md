# Node Lab public-source agreement

This repository is a portable Node-RED learning simulation. Keep it local-first
and safe to publish.

- Use no customer data, physical device endpoint, private host address,
  deployment topology, credential, token, cookie, analytics or external
  browser asset.
- Keep the default listener on 127.0.0.1.
- Keep all workshop values explicitly emulated and separate from actual
  aggregate application telemetry.
- Scenario selection must affect only one read-only response. Do not persist a
  visitor-selected scenario or create shared public writable state.
- Retain strict fixed-value validation for the 22 C, 34 C and rejected 99 C
  lesson. Do not add arbitrary flow deployment, shell execution or URL input.
- Label absent hardware and absent live AI inference wherever behavior could
  be misunderstood.
- Production infrastructure, credentials, release evidence and operator memory
  live outside this public repository.
