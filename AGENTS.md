# Node Lab public-source agreement

This repository is a portable, synthetic Node-RED learning demo. Keep all
examples local-first and safe to publish.

- Use no customer data, real device endpoint, private host address, deployment
  topology, credential, token, cookie, analytics or external browser asset.
- Keep the default listener on `127.0.0.1`.
- Public input remains fixed to 22 C and 34 C; 99 C is the intentional invalid
  test. Do not add arbitrary flow deployment, shell execution or URL selection.
- Label synthetic data, absent physical hardware and absent live AI inference
  wherever behavior could be misunderstood.
- Production infrastructure, release evidence and operator memory live outside
  this public repository.
