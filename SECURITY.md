# Security and truth boundary

- Workshop temperatures, power and process values are generated by the bundled
  Node-RED Function every 1.5 seconds. They are emulated, not sensor readings.
- Real telemetry is limited to aggregate software counters and timings: ticks,
  API responses, processed messages, uptime and function build latency.
- Normal, heating, fault and recovery are allowlisted read-only transformations
  of one response. No visitor-selected scenario is written to shared state.
- The retained validation endpoint accepts exact JSON numeric samples 22 and
  34 from its configured same origin. The deliberate 99 and string tests
  return 400 before browser state changes.
- Production sets httpAdminRoot to false. The optional editor profile binds to
  loopback and uses a separate volume.
- The container runs non-root with a read-only root filesystem, dropped
  capabilities, no-new-privileges, resource limits and no Docker socket.
- Browser assets are first-party. There are no analytics, accounts, cookies,
  third-party fonts, model APIs, hardware bridges or customer data.

This is an educational simulation, not an industrial control system, safety
controller or proof of physical hardware behavior.

Report security concerns privately to the repository owner. Never include
credentials or sensitive production details in a public issue.
